 隧道窗口已经开好了，去那个窗口里找公网地址：

   cloudflared -> 框起来的那一行 https://xxxx.trycloudflare.com
   ngrok / cpolar -> Forwarding 那一行的 https 地址

 把地址后面接上 /coop.html，比如：
   https://xxxx.trycloudflare.com/coop.html

 这就是两个人都要打开的网址 —— 手机流量、别人家的 WiFi 都行。

 注意：
  1. 一定用 https 那一条，不要用 http 那一条
  2. 这个地址每次重启都会变，每次重开都要重新发给队友
  3. 三个窗口都不能关（这个、服务器、隧道），关了队友就掉线
  4. 电脑不能休眠

 如果隧道窗口里只有报错：
  ngrok  -> 先跑一次 ngrok config add-authtoken 你的token
  cpolar -> 先跑一次 cpolar authtoken 你的token
  cloudflared 不需要任何配置，报错多半是网络连不上 Cloudflare
