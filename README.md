# 幽墟回廊

一个用背单词打怪的地牢 Roguelike。答对一题 = 砍它一刀，答错 = 它咬你一口。
石廊共 **50 层**，词汇从 CEFR **A1 一路爬到 B1**，尽头蹲着石廊守卫。

**在线试玩**：https://audience20060904-lang.github.io/youxu-huilang/

## 玩法一句话

从灰岩镇进洞，每层清掉约 3 只怪才开下行阶梯。你 20 点血、一刀 3 点伤害，
数字都小到能心算出「还要答对几个」。变强的唯一轴是 **遗物**（48 件、5 个品质、最多带 10 件），
倒下时遗物和等级全丢在洞里，**只有金币、词汇熟练度和图鉴能带回镇上**。

## 存档

进度存在浏览器本地，**边玩边存**：走一步、打完一架、切后台都会写一次，中途关页面丢不了，
下次打开会问要不要接着走。

设置页里可以把这台设备上的**全部存档**（词汇熟练度、遗物图鉴、探索记录、镇上存款，
连没走完的那一趟）下载成一个 `.json` 文件放在自己手里。换设备、换浏览器、清过缓存，
把文件选回来（或者直接拖进去）就接着玩 —— 选中就自动读出来，先看清楚里面是什么，
再决定是**合并**（两边取更好的那份）还是**整档覆盖**。

不方便传文件时还有一段跨设备导出码，只带永久数据，不带那一趟。

## 文件结构

纯静态，没有构建步骤，没有依赖。`index.html` 按下面的顺序加载脚本，**顺序不能乱**：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：四个标签页 + 十个弹层 |
| `style.css` | 全部样式，颜色变量在 `:root` |
| `util.js` | 全局小工具（随机、存档、发音），必须最先加载 |
| `words-a1.js` | 词库 430 词，格式 `[英文, 中文, 类别, 难度]` |
| `content.js` | 数值配置：章节、怪物、遗物。**调平衡只改这里** |
| `art.js` | SVG 美术，剪影用 `currentColor`，颜色交给 CSS |
| `game.js` | 全部游戏逻辑 |

### 加词

往 `words-a1.js` 的 `WORDS` 里加一行，四个字段都要给，类别必须在 `CAT_CN` 里有对应中文名。
**英文不能重复** —— `WMAP` 按英文做键，重了会被静默覆盖。索引是派生的，加完自动生效。

### 加遗物

在 `content.js` 的 `RELICS` 里加一条，然后在 `game.js` 里加对应的 `hasRelic("id")` 分支 —— 两边必须同步。
数值规矩：**全是整数加减，整个伤害公式只有「暴击 ×2」一个乘区**，别引入第二个乘法。

## 本地运行

`file://` 打开也能跑，但用个静态服务器更稳：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

## 部署

**一次性设置**：Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。
只需要点这一次。这步没法写进 workflow —— Actions 的令牌没有创建 Pages 站点的权限。

设置完之后，推到 `main` 就自动发布 —— `.github/workflows/deploy.yml` 会把游戏文件打包丢到 GitHub Pages，
通常 30～60 秒后线上就是新的。不需要手动操作，在 GitHub 网页上直接改文件也算数。

页面顶部内置了报错横幅：出问题会直接显示在页面上，不用开 F12。
